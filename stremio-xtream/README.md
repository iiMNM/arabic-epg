# Stremio Xtream — إضافة Stremio لأي اشتراك Xtream

إضافة لـ **Stremio** تعرض **القنوات المباشرة + الأفلام + المسلسلات** من أي اشتراك Xtream Codes
(سيرفر + يوزر + باسورد). ما تحتاج مكتبات، وتشتغل على **Vercel** مجاناً (أو Deno Deploy / Render / أي سيرفر Node).

**النسخة المنشورة:** https://stremio-xtream-mnm.vercel.app/configure (مشروع `stremio-xtream-mnm` على Vercel)

## المميزات

- 📡 **قنوات مباشرة** مع تصنيفات السيرفر (فلتر Genre) و"وش يعرض الحين" من الـ EPG داخل صفحة القناة
- 🎬 **أفلام** مع البوستر والقصة والتصنيف وسنة الإنتاج والتريلر (الأحدث أولاً)
- 📺 **مسلسلات** بالمواسم والحلقات
- 🔍 بحث في كل قسم (يتجاهل التشكيل والهمزات: `الجزيره` = `الجزيرة`)
- 🔒 بيانات الدخول **مشفّرة** داخل رابط الإضافة (AES-GCM) لو حطيت `CONFIG_SECRET`
- تقدر تركّب أكثر من اشتراك، كل واحد باسم مختلف
- البث نفسه يروح من جهازك للسيرفر مباشرة — ما يمر على Vercel، فما فيه استهلاك باندويث

## النشر على Vercel

1. [vercel.com](https://vercel.com) ← **Add New → Project** ← اختر مستودع `arabic-epg`
2. **Root Directory** ← `stremio-xtream`
3. **Environment Variables** (كلها اختيارية بس الأول مهم):

| المتغيّر | الوصف |
|---|---|
| `CONFIG_SECRET` | أي نص عشوائي طويل (`openssl rand -hex 32`) — يشفّر اليوزر والباسورد في الرابط. **لا تغيّره** بعدين وإلا الإضافات المركّبة توقف |
| `DISPLAY_TZ` | توقيت جدول البرامج (الافتراضي `Asia/Riyadh`) |
| `XT_UA` | User-Agent اللي ينرسل لسيرفر Xtream (الافتراضي `IPTVSmartersPro`) |
| `CACHE_SECONDS` | مدة حفظ القوائم في الذاكرة (الافتراضي 900 = ربع ساعة) |

4. **Deploy** ← افتح `https://<اسم-المشروع>.vercel.app/configure`

## التركيب

1. افتح صفحة `/configure` وحط رابط السيرفر (مثل `http://example.com:8080`) واليوزر والباسورد
2. اضغط **تحقّق وولّد رابط التركيب** — الصفحة تتأكد إن الحساب شغّال وتعرض تاريخ الانتهاء
3. اضغط **تركيب في Stremio**، أو انسخ الرابط والصقه في خانة البحث في صفحة الإضافات

> تقدر تستخدمها مع [Xtream Bridge](../xtream) حقك: حط رابطه كسيرفر ونفس `XT_USER` / `XT_PASS`.

## تشغيل محلي / سيرفرات ثانية

```sh
cd stremio-xtream
CONFIG_SECRET=xxxx node server.js     # http://localhost:7000/configure
```

- **Deno Deploy**: Entrypoint `stremio-xtream/main.ts`
- **Render / Koyeb / Railway**: Root `stremio-xtream` ← Start command `node server.js`

## ملاحظات

- **بعض سيرفرات IPTV تحجب IPات الاستضافة** (Vercel وغيره). لو صفحة الإعداد قالت "ما قدرت أتصل بالسيرفر"
  والبيانات صحيحة، جرّب `XT_UA` ثاني، أو شغّل الإضافة على جهاز بالبيت (`node server.js`) أو VPS.
- القنوات اللي على `http://` تشتغل في تطبيقات Stremio (ويندوز، ماك، أندرويد، TV). **Stremio Web** في المتصفح
  غالباً ما يشغّلها لأن المتصفح يمنع `http` و `.ts`.
- لو قناة ما اشتغلت بـ HLS، جرّب خيار **MPEG-TS** في قائمة الروابط (أو غيّر الصيغة المفضّلة من الإعدادات الإضافية).
- القنوات تحتاج طلب EPG لكل قناة عند فتحها، فـ"وش يعرض الحين" يظهر في صفحة القناة مو في القائمة.
